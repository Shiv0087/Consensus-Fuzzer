Nodes A & B run the current EVM hardfork (Cancun). Node C intentionally runs an outdated hardfork (Shanghai) to reproduce the real-world scenario where lagging client versions disagree with the rest of the network on how to execute a transaction — the same class of bug behind real historical consensus incidents.

Note on the chain state panel above: each node here is an independent local chain, so block hashes differ across nodes by construction even when they fully agree on every transaction. Divergence is determined by comparing each node's execution outcome (success/failure, return value, revert reason) for identical transactions — the chain state panel is shown for educational visibility into block structure, not as the divergence signal itself.
